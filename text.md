# JavaScript ASync


## javascript is an synchronus language which executes the code line by line by default.
## also it is a single threaded language.

we always use javascript with some other runtime enviroments like browser

in this default case each operation waits for the last one to finish before executing 


# blocking vs non blocking code

blocking code blocks the flow of program (read file sync)

non blocking code doesn't block execution of the program (read file async)
